Problem Scope

Multi-agent warehouse coordination must satisfy throughput and safety constraints under dense traffic. This project models agents on a grid with pickup/drop tasks and enforces collision-free behavior through deterministic planning and bounded verification.

Safety Objective

Maintain minimum inter-agent separation and avoid collisions across a finite horizon, while completing shelf delivery tasks.

System Overview

Agents operate on a discrete grid with pickup/drop objectives. Planning is deterministic (Cooperative A* with CBS conflict resolution). Safety is checked via bounded verification on a symmetry-reduced quotient model.

Run Interactive Locally

The interactive renderer uses pygame for real-time visualization of agent trajectories, pickups, deliveries, and collision avoidance. 

python main.py --mode interactive --render

Tip: If it feels slow, reduce grid size or steps in config.yaml.

Other Commands

Formal Verification (Symmetry-Reduced)

Safety is verified on a quotient model obtained by orbit-based symmetry reduction. Counterexamples yield constraint updates and trigger re-verification. 

python main.py --verify-refine --verify-horizon 30 --verify-trials 20

Algorithm Details

Planning

Cooperative A* plans time-expanded paths with reservations; CBS resolves conflicts by adding constraints and replanning affected agents.

Symmetry

Agents are partitioned into role orbits. Canonicalization maps symmetric permutations to a single quotient state.

Verification

Bounded verification checks collisions and minimum separation on the quotient; unsafe traces generate counterexamples.

Refinement

Counterexamples are compiled into hard constraints, steering the planner away from unsafe transitions.

Configuration Reference

Configure grid size, agent count, planning horizon, and verification budget in config.yaml. 

planning:
  horizon: 40
  use_cbs: true
  cbs_max_nodes: 200
  astar_max_nodes: 6000
  idle_limit: 6

verification:
  horizon: 30
  trials: 20
  min_separation: 1

Verification Outputs

The verification loop reports progress per trial, the safety margin delta_q, average collision rate, and a sample of final constraints. 

Verification passed at iteration 2 (delta_q=0.50)
Average collision rate (per step): 0.0000
Final constraints: 3 positions, 1 edges

Limitations

Verification is bounded in time and trials. Refinement relies on extracted counterexamples and may require multiple iterations to converge for dense layouts.

Recommended Usage

Use smaller grids or lower verification budgets for quick iteration, then increase budgets for stronger assurance.
